## 🎯 核心创新：位交叉异或降维

传统 CRC 实现将算法视为**串行多项式除法**，每字节需8次循环。本实现将 CRC-16 重新定义为 **GF(2)上的线性变换**，利用 ARM 桶形移位器实现并行位运算。

### 关键洞察：信息论最优降维路径

```
8位 → 4位:  XOR LSR #4  （位0-3与位4-7交叉）
4位 → 2位:  XOR LSR #2  （位0-1与位2-3交叉）
2位 → 1位:  XOR LSR #1  （位0与位1交叉）
```

三次交叉异或将8位输入坍缩为**1位奇偶校验值**，再基于该值展开16位多项式修正。这是信息论下限附近的最短计算路径。

### 为何重要

| 瓶颈 | 传统方法 | 本方法 |
|------|---------|--------|
| 计算模型 | 串行（逐位） | 并行（全位同时） |
| 条件分支 | 需要（if-else） | 消除（乘法或IT块） |
| 桶形移位器利用 | 无 | 最大化（免费移位） |
| 每字节周期 | 80+ | 约12 |

## 🔧 使用方法

### 函数版

```asm
    LDR     R0, =data_buffer    ; 数据指针
    MOV     R1, #10             ; 数据长度
    BL      ModbusCrc           ; 调用函数
    ; 结果在 R0（已做 REV16 字节序交换）
```

### 宏版（中断优化）

```asm
    ; USART 接收中断内
    LDRB    R2, [USART_DR]      ; 读取接收字节
    LDRH    R0, [CRC_VAR]       ; 当前 CRC 值
    MCRC16  R0, R2, R1          ; 12周期宏指令
    STRH    R0, [CRC_VAR]       ; 更新 CRC
```
